## 使用方式

本项目在 Codex 辅助下完成。AI 参与需求拆解、技术方案、程序实现、测试设计、运行调试、文档和提交材料整理。仓库中的运行证据由实际执行程序产生，没有由模型手写成功日志替代运行。

开发助手与被测试的 Agent 模型是两个角色：前者辅助构建项目；后者通过 `src/providers.py` 接收业务状态并选择下一动作。Mock 是固定测试桩，与真实模型证据分开。
