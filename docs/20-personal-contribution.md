# 个人实际投入与贡献说明

本人实际投入约4小时，分多轮完成。该时间根据2026年11月3日至6日的聊天与人工测试记录事后估算，已由本人确认，主要用于需求分析、网页人工试用、生成内容审阅、问题反馈、迭代决策及提交核对。AI在后台编写代码、执行自动化测试和批量模型实验，以及模型调用的等待时间不计入个人投入。

我在比较四道题后选择了“短视频脚本Agent”，并提出增加简单网页，方便直接输入需求、查看脚本和执行过程。随后多次通过网页进行人工试用，检查输出是否易懂、旁白是否适合直接配音，以及人物动作和对白是否自然、连贯。

人工试用中，我反馈了旁白表达生硬、分镜动作不充分、“同拍声画同步”等术语不直观，以及模型调用失败等具体问题，并据此调整优化重点。我也指出原产品示例资料过薄，要求接入已有《城寨风云》的故事、人物和场景，以熟悉的剧情进一步检验生成效果。

在验证方式上，我要求保留旧版本和全部测试记录，通过网页使用真实模型测试，场景贴近实际需求，不根据预期结果反推输入。根据实验暴露的问题，我确定了时长审核、异常记录保存、调用稳定性及文案质量等修复重点，并要求对照原笔试要求复核交付内容。

代码实现、故障定位、自动测试、批量模型实验和文档整理主要由Codex辅助执行。我的实际参与集中在需求与范围判断、人工试用、具体质量反馈和迭代决策；自动实验次数不计作本人手动测试次数。

时间按个人实际参与估算，没有将整个项目的日历跨度或两条消息之间的全部间隔当作工时。由于没有连续人工计时记录，不给每项活动填写精确到分钟的数字。原有代码、历史版本和测试记录保留，本文补充个人投入与协作分工。
