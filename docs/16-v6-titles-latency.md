# v6：让标题更具体，减少等待与超时中断

本轮针对 v5 实测的三个问题：22份稿件套用示例标题、两次写稿调用超时、50次任务中位耗时314.1秒。保留单Agent与全部事实/需求检查，没有通过放宽完成门槛提高完成数。

## 实现变化

|变化|为什么做|如何保留可核验性|
|---|---|---|
|creative不再收到strict标题、连接语与画面白名单；提示从具体场景/对象/看点提炼标题|去掉四个通用示例的锚定，保留指定标题|strict规则和原数据不变，逐例对照实际标题|
|历史只带动作、简短依据与失败摘要；当前稿/当前检查/检索事实仍完整|减少每次重新发送历史稿件与重复检查|原始Trace完整保留，压缩只作用于下一次模型输入|
|check_requirements补齐当前稿的本地时长/规则检查，再进行独立模型审核|不为两项本地计算分别等待模型选动作；发现本地失败先修订|每项预检查的工具名、参数、真实返回保存在preflight_checks，可重放；模型仍决定改稿/补查/停止|
|Codex子进程使用medium推理强度，可用CODEX_REASONING_EFFORT覆盖|避免继承本机xhigh用于每个简短动作|记录reasoning_effort，不修改全局配置，不虚报具体远端型号|
|整次运行最多恢复一次真实Codex超时|偶发超时后保留上下文继续，不立即放弃|每次尝试单独诊断、原失败保留；每调用仍180秒，业务工具不重复执行，取消后不再恢复|
|网页显示预检查、审核、恢复阶段和合并工具的真实结果|等待时能看懂正在做什么|不伪造进度或预设成功结果|

标准成功路径可由7次模型响应减少到5次（检索、写稿、选择审核、独立审核、结束）；这只是结构上的机会，实际次数仍取决于模型选择和修订。

129项自动测试通过，包括来源/时长/需求门槛、超时恢复预算与诊断关联、取消边界、检查点中断、检索变化后重查规则。独立代码审查发现的两项重要问题已各自以失败回归测试复现并修复。v5全部50条历史记录仍可重放。

## 具体成稿变化

- **V01，改进：** 标题从通用“字幕，让表达被看见”改为早餐摊备料与口播字幕，三个画面顺序、只讲添加字幕和不露顾客正脸均保留；蒸笼镜头增加前后字幕效果对照。响应7→5。 [实际脚本](../evaluations/realistic-50-v6-20261105/runs/V01/script.md)
- **V05，改进：** 旧版检索后写稿自然超时，无成稿。新版查到两类事实，首稿时长超限后仅精简第三镜旁白，完成34.5秒三镜脚本；三段修理铺素材、两项功能及禁止维修安全讲解/虚构按钮均落实。失败预检查和具体修订已保存；没有重跑覆盖。 [实际脚本](../evaluations/realistic-50-v6-20261105/runs/V05/script.md)
- **V14，改进：** 标题明确球场日常与社团视频；开头、记分牌字幕和结尾从旧模板串场改为边线记录、训练记录、人物构图观察。三种场景与三项功能各一次均保留，无成绩提升宣传。正文与标题一起更贴场景，响应7→5。 [实际脚本](../evaluations/realistic-50-v6-20261105/runs/V14/script.md)
- **V22，改进：** 旧标题把想法放进画面泛化，新标题点名展厅入口与画册、横竖屏。两版均28秒；新稿中文voice和对应英文screen逐拍分开，双框构图与最后入口全景/画册近景对应，未编造自动翻译能力。 [实际脚本](../evaluations/realistic-50-v6-20261105/runs/V22/script.md)
- **V28，改进：** 旧版写稿超时而无成稿；新版完成五镜44.4秒，以分享会发言、花园字幕改字和合影边缘串联四项能力。预检查发现首稿时长问题，模型仅精简末镜后重检通过，7次有效响应；本例没有超时恢复，不把完成归因于重试。 [实际脚本](../evaluations/realistic-50-v6-20261105/runs/V28/script.md)
- **V45，改进：** 两版均先估出原稿45秒，再保留指定标题、原文与三镜顺序，优先缩短停留。新稿16秒给出准各改准备和字幕出现的具体示意，旧稿13秒的改字对象较泛；新稿交接更具体，响应8降6。并非用更短时长作为改进依据。 [实际脚本](../evaluations/realistic-50-v6-20261105/runs/V45/script.md)

这些变化对应原题的实际成稿、有效修订和事实可追溯。通过减少无用决策和提示干扰改善结果，未增加审核层或生产功能。

## 当前边界

- 仍是估计视频时长，没有TTS或成片实测；需要事实资料时说明具体缺口。
- 有些示例字幕只写在画面说明中，没有独立的screen文字块。本轮V03、V18、V21出现这种交接细节取舍，最终评阅为相当；标题变具体不等于正文全面提升。
- 模型仍可能先写出资料未证实的界面细节。V30首稿出现时间线描述，审核发现后删改，最终完成但比旧版多一次响应；本轮没有把首次出稿质量包装成全部无误。
- 超时恢复不是无限重试，最多增加一个180秒调用；若仍失败则保留已有结果并明确未完成。
- 取消正在进行的决策调用时，如果该调用随后超时，仍显示blocked而非cancelled；不会再恢复或开始后续动作。独立审查将此列为既有次要状态文案问题，本轮保留。
- 保留Codex默认运行时上下文，未替换其基础指令或调整用户全局配置；其输入开销仍存在。
