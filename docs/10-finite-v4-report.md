# v4 有限修复与原题收益报告

本轮以第4题原要求为边界，修复实际估时未进入需求审核上下文、以及异常情况下运行记录丢失的问题。未扩大为视频生成、发布、生产级运行平台，也未放宽事实引用、目标区间或12步上限。原题要求“至少两条不同执行路径”和“至少三组输入、实际输出、Trace”；本轮材料是对既有完整验收的补充，不替代历史的缺信息、无素材、工具失败与超时修订证据。

## 修复了什么，为什么这样改

|实际问题|本轮修改|对应原题的价值|
|---|---|---|
|估时工具已判定合格，但审核模型没有拿到工具结果，又要求补时长证明|把同一稿件的逐镜估时、总时长、目标与模式送入需求审核；不匹配稿件哈希或目标的结果不会复用|模型依据真实工具观察决定下一步，减少无效回环；提升“有效修正”的可解释性|
|`hold_seconds=0`被理解成镜头时长为零|明确其含义是额外指定的最短停留，真实估时还考虑文字朗读与阅读；审核优先使用`estimated_seconds`|避免因字段语义误解拒绝可用脚本；仍保留局部节奏和内容审核|
|Windows临时目录清理失败，掩盖已成功收到的模型响应或原始错误|模型响应与清理分开处理，清理失败记录`cleanup_deferred`；每次调用保存独立脱敏诊断|工具/模型故障可追溯，成功观察不会被无关清理异常丢弃|
|结束时才保存，运行中断没有正常产物|首次调用前保存输入和数据，逐步以原子替换保存检查点；异常时保留最后有效草稿、检查与Trace，并返回未完成|异常路径也提供实际证据，不虚报成功，便于评审复算|
|最终文件写入失败或进程退出后难以判断残留记录状态|最终输出最后写入，以`run.json`标记保存状态；恢复检查点时验证运行ID并跳过存活进程，恢复后明确为blocked，不续跑模型|区分业务未完成、保存失败与完成记录，避免恢复过程改写正在运行的任务|
|人工测试异常时只能依赖截图|网页增加检查点下载；CLI与网页共用记录层|符合“截图不能替代代码/执行记录”，降低人工复盘成本|

这些是基于题面验收与审核要点的收益解释，不代表招聘方已评分，也不保证录用结果。

## 验证方法

自动测试先复现再修复：原始失败记录见`regression-before.txt`及`owner-guard-before.txt`；最终95项测试全部通过，8组Mock验收通过。Mock用于可控验证宿主和故障路径，不能证明真实模型决策。

真实模型复测沿用上一轮事先冻结的V26、V27、V28、V29、V46和V01原始需求，没有按新实现改写需求。另以V01输入开展清理失败、草稿后运行异常、草稿后进程退出三个受控故障实验；模型动作与草稿来自实际Codex调用，故障由实验脚本明确注入。自然需求与受控故障不合并计算业务成功率。模型使用当时CLI默认配置，不据此宣称精确远端模型版本。

最终统计、逐条人工阅读式评阅和复算入口见[复测目录](../evaluations/finite-v4-20261104/README.md)。评阅由同一AI开发助手完成，未做独立盲评或统计显著性检验。

## 尚未修复或不在范围内

1. **语义审核仍可能误判。** 补足估时事实不能保证平台适配、表达、节奏判断总是正确；没有加入独立第二模型裁决，也未调高12步上限。
2. **时长仍是估算。** 未进行实际配音、TTS对齐或成片测量。字幕事实卡和口播在同一文本结构中，阅读与朗读节奏仍需人工核对；90%–100%是本项目约定，不是题面规定。
3. **逐字事实引用仍较严格。** 英文改写、极短卡片、自然口语改述可能受限；本轮没有放宽来源规则以换取更多completed。
4. **保存有明确边界。** 只恢复最后成功写入的检查点；断电/进程退出时当前尚未返回或尚未写入的步骤可能缺失。磁盘持续不可写、首个检查点未能落盘时不能保证恢复。多个最终文件不是数据库事务；依靠完成标记识别中途保存。
5. **不自动续跑。** 恢复只生成blocked证据，不重新消耗模型额度。存活进程检测保守，权限不足或PID复用可能暂缓恢复；不提供跨进程协调和自动接管。
6. **模型服务不可用仍会影响任务。** 容量、登录、超时等失败保留为失败；不会切换Mock冒充真实模型成功。清理失败可能留下临时目录，尚未做后台清理服务。
7. **素材与业务能力仍是原范围。** 使用合成产品资料，没有真实企业资料库、上传管理、视频生成或发布。网页仅是本机人工测试入口。
8. **交付尚差外部提交。** 本地ZIP不是Git提交；还需把最终材料上传到GitHub，取得与远端一致的最终commit SHA，并给指定评审账号读取权限。未替用户提交考试页面。候选人个人贡献与复验只能按实际行为填写。

## 复核命令

在项目根目录执行（输出到新目录，避免覆盖本次证据）：

```bash
python -m scripts.run_tests --output outputs/reviewer-v4-tests
python -m scripts.evaluate --provider mock --output outputs/reviewer-v4-mock
python -m scripts.audit_finite --require-complete
python -m scripts.evaluate_finite --case V29 --output outputs/reviewer-v4-real-V29
```

最后一条会调用真实模型并消耗账号额度；结果可能因模型随机性不同。`audit_finite`只复算已保存记录及哈希，不调用模型、不证明所有语义正确。完整ZIP包含历史根目录归档以满足3128项哈希复核；若另行提交精简仓库，应说明证据范围。
