## 设计与验收

1. creative 模式不再把 strict 的示例标题、连接语和画面白名单作为创作提示；标题由场景/对象/实际内容生成，保留用户明确指定标题。strict 保持原语义。
2. 模型输入使用当前稿、完整当前检查、检索事实与简明历史；不在每个历史步骤重复整篇稿件。完整原始 Trace 仍落盘。
3. check_requirements 在必要时先执行并记录本地时长/规则检查，再进行独立模型审核。遇到确定性失败时先反馈模型修订，不白花一次语义审核。模型仍决定检索、写稿、修订、结束；不是预设修订结果。
4. Codex 每调用明确 medium 推理强度（可配置），不修改用户全局配置/模型选择。一次运行至多恢复一次真正的超时，每次调用仍受原180秒上限；每次失败与成功都有独立诊断，恢复不重放业务工具。取消后不再恢复。
5. 网页显示当前审核/重试阶段。结构化输出约束与已有运行时约束一致，减少空文案块的无效往返。
