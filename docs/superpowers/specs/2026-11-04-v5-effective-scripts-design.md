# v5：提高脚本实际可用性

用户已明确授权三项优化、保留旧版及全部记录、网页真实模型50次配对复测。沿用 Python 标准库、现有网页与模型适配器，不扩展到视频生成。

## 选择与范围

仅加提示词不能解除逐字引用及串行估时限制；全面重建多Agent增加无关复杂度。本次采用兼容旧格式的结构改进，并同步调整生成/审核提示。

新稿 format_version=2，旧稿仍可读取、检查及修订。每镜 purpose 记录内容目的（不是公开文案）；每块仍有 text/source_id/fact_id，增加 channel(voice/screen/both)、beat(1–8)、display_seconds(0–300)。同一beat同时开始；其中旁白依次读、屏幕文字同屏展示，全部屏幕字都计阅读预算；不同beat依次播放。屏幕展示时长不得短于阅读估计，镜头时长取各beat累计与最低停留较大者。中文按字、英语按词分别估计；中文语速4字/秒、英语2.5词/秒，屏幕阅读采用同样基准，非TTS测量。

创作模式v2允许有来源事实缩写、改写和翻译。宿主从已检索素材提取原文保存到citations，校验ID与品牌规则；审核逐条判断改写是否由该原文支持。带来源的块必须得到supported_claim且审核引用与块来源一致，普通表达不能冒充事实；strict和所有旧格式维持原约束。新稿所有公开表面均进入审核。无需把产品全名重复在每句，也无需添加未要求的相邻功能。

生成时先落实范围、语言、场景、镜头顺序，再让每镜服务具体信息或动作。purpose只帮助组织，不能代替实际画面与文案。避免空泛串场及固定广告套路；原稿修订优先保留有效部分。提示中不注入实验题目/答案。备注只写已做改动或真实资料缺口，不记容易过时的检查状态。

## 验证与交付

新测试覆盖语义引用门槛、翻译、压缩、同步/串行卡片、静音、不同语言、旧稿兼容、格式畸形、修改后的检查失效和实际记录复算。原101项测试继续运行。

保留v4.1源码ZIP及旧文件哈希。50次正式实验沿用上轮冻结输入（49种需求与一次预定重复），从网页输入，选择真实Codex，无故障注入。每个实际尝试保存输入/输出/Trace/截图/模型诊断，不用补跑替换有响应的失败。固定版本后实验中不修改程序；必要开发冒烟单独存放。按相同需求逐稿比较，不把completed数量单独等同质量，不要求真正缺资料的场景编出事实。
