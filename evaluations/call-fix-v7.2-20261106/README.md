## 修复了什么

1. **减少无关配置和重复输入。** 内置模型服务下，结构化子调用隔离个人 MCP 等配置，显式保留模型及服务档位，不改全局配置；自定义供应商或 profile 保持继承。决策阶段省去重复的已通过明细，完整依据仍送入独立审核并保存。对原失败状态，状态JSON从41809降至25873字节，减少38.1%，不代表总模型token同比降低。
2. **恢复预算不再过早耗尽。** 单次调用最多重试一次，全任务最多额外恢复两次。前面已经恢复过的情况下，后续审核仍有一次恢复机会。已执行的业务工具不重放，12步上限不变。
3. **审核失败后及时结束。** 适配器恢复仍失败时，保存草稿和审核失败记录，直接返回未完成，不再发一次无用的后续决策请求。
4. **保留可定位的超时诊断。** Windows进程终止后回收尚未读完的输出，再提取调用阶段、耗时、事件计数、是否开始/完成及错误类别。只保存脱敏信号，不写入原始事件正文、内部推理或凭证。网页区分决策重试与审核重试，失败提示说明具体阶段。

这些修改直接改善“能运行、有记录、可解释改动和验证结果”的原题要求；完成门槛和事实审核没有放宽。
