# v5真实成稿对比口径

输入沿用已经冻结的50需求。评阅内容不发送给被测模型，不根据输出改题。
逐条阅读原始需求、新旧实际稿件和关键Trace，记录：
1. 硬条件：范围、语言、镜头顺序/数量、字数与时长；完整/部分/未完成。
2. 表达：准确自然的改写/翻译，是否仍机械复述；必须指出原句对比。
3. 制作可用性：场景动作、具体信息、声画安排、可执行时间；不凭篇幅打分。
4. 有效修订：错误后是否实际改动并复检，是否破坏已满足的约束。
5. 来源：新声明能否由引用原文支持；不以ID存在当作语义成立。
6. 成本：实际步骤、模型响应、审核/修订次数。缺真正事实的正确追问不计为能力缺陷。

每例review.json显式记录观察，不自动按completed打质量分。分改进/相当/退步/仍需补充四类，并写依据。所有未完成保留，报告包含实际退步；模型本身审核与开发助手事后评阅分开。
