# 50 次网页现实需求测试复盘

## 结论

共完成 **50 次网页提交、50 份独立归档**。程序返回 **29 次 completed、21 次 needs_input**。这些是程序状态，不是业务验收通过率。

基础功能介绍、固定镜头和旧稿压缩表现可用；无依据的功能、价格、效果数字及跨产品内容没有被直接写入最终成稿。主要问题是创作范围被静态句库限制、部分具体场景未落实、完成摘要丢失模型给出的取舍说明，以及长稿依赖延长镜头停留。当前更适合作为受控素材下的 Agent 演示，仍不能当作通用创作工具。

## 方法与证据

- 执行时间：2026-11-03 21:42:52 至 2026-11-03 23:17:58，北京时间。
- 50 条执行项在第一条运行前全部写好并冻结。内容来自校园采访、门店宣传、生活记录、展位播放、客户改稿等模拟业务简报，未根据“应该看到什么”反推，也未根据运行结果修改后续场景。
- 共有 48 条不同简报；T49 原样重复 T01、T50 原样重复 T11。重复项在初始清单中预先安排，不能称为 50 条互不相同的场景。
- 全部在同一个网页填写表单并点击“生成并检查”；旧稿经网页旧稿输入框提交。没有通过后端接口或命令行直接发起测试。
- 每项仅执行一次；没有为了变绿重试、替换失败记录或修改应用/提示词/素材/规则。归档与离线复算使用本地脚本，不触发模型执行。
- 运行方式全部选 Codex。47 条实际调用了模型，共 209 次决策响应；T31–T33 缺关键字段，在模型调用前返回。没有使用 Mock 或注入工具故障。Trace 的模型名称是 `CLI configured default`，本报告不推断具体模型型号。
- 代码基准：`e624c5a872f26fb0689fcc6a3e246da35edccbb7`；冻结清单 SHA-256：`b363aa99c320ff4a2ec0ff63939c60eb56758528c9af27a2367d6f010a8d0db5`。应用与数据文件哈希复核未变。
- 所有 50 条输入与冻结简报一致；网页“原始结果”的结果字段与本地 output.json 一致，额外展示的 trace 与 trace.jsonl 一致。离线工具观察复算均无差异。复算证明本地记录与工具规则一致，不独立认证远端模型过程或实际视频效果。

## 解释边界与下一步

实际调用模型的单次运行耗时中位数为 85.7 秒，最长 153.9 秒。这包含当前本机与服务条件，不是性能基准。
本轮使用合成产品素材，不能证明真实产品功能、真实客户转化或成片时长。测试中没有主动注入工具故障，也没有覆盖并发、取消、浏览器刷新恢复和长时间负载，不能替代这些专项测试。needs_input 既包含合理的事实不足，也包含规则限制正常创作，应逐例解释。
建议先保留本轮为基准，再修复完成摘要、需求覆盖检查和补充入口；随后放宽表达方式并维护来源对应关系，最后用同一冻结清单做新版本对照。本轮未修改应用，也未提交或发布笔试项目。
