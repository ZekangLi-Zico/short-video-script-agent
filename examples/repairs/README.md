# 有限修复验证索引

本目录只保存原题范围内的修复版回归。原 `examples/live/`、`examples/mock/` 及 `evaluations/realistic-50-20261103/` 不覆盖。

- `mock/`：八个原题验收场景的固定离线桩运行，不证明语义理解。
- `live-verified/`：第一阶段在正常本机权限下执行的真实 Codex 模型八场景验收。缺信息场景仍是前置校验。
- `ui/T02/`、`ui/T28/`、`ui/T43/`：从原 50 次冻结输入选取三条原样网页复测，保存页面原始结果、截图、页面文字和六类后端产物。
- `ui/T43/` 暴露需求核对缺少事实依据导致误拒绝；原记录完整保留。补上传递实际事实检查依据后，原输入复测另存 `ui-final/T43/`。
- `live-final/`：最后补修后的正常、超时修订针对性真实模型回归；没有重跑所有八个真实场景。`mock-final/` 是最后补修后的八场景离线回归。
- `live/`：首次尝试遇到本机沙盒阻止 Codex 写入自身状态数据库，七个需模型场景均未成功获得响应。保留原始失败，不作有效模型验收证据。
- `audit.json`：运行 `python -m scripts.audit_repairs` 生成，检查原冻结文件哈希、修复产物本地复算、网页输入/结果一致性，并以新验收规则重新评估首次失败尝试。

完整修复效果与未解决事项见 [有限修复报告](../../docs/08-limited-repair-report.md)。状态变化不等于总体成功率提升；本轮没有重跑全部 50 条。
